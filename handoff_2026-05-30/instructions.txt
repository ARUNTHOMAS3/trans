2. HOW TO INTEGRATE THESE FILES WITH YOUR MAIN PROJECT
------------------------------------------------------------------------

Since all files under the `handoff_2026-05-30` directory are saved inside a
folder structure that mirrors your main repository, integration is extremely
simple:

### Step 1: Copy-Paste Handoff Files
Copy everything located inside the `handoff_2026-05-30` folder (except the 
`instructions.txt` and `file_paths.txt` index files) and paste it directly 
into the root directory of your project (overwriting any existing files when
prompted).

### Step 2: Sync Frontend Dependencies & Rebuild
Open your terminal in the project root directory and run the following command
to install potential dependencies and perform static code analysis:
```bash
flutter pub get
flutter analyze
```
Ensure there are no errors in the analyzed scopes.

### Step 3: Run Backend Migrations & Build
Open your terminal in the `backend/` subdirectory and run:
```bash
cd backend
npm install
npm run build
```
Verify that the NestJS compilation builds successfully.

### Step 4: Apply Database Schema & Constraints
If there are new schema definitions:
1. Run Drizzle generation to sync TypeScript classes with PostgreSQL tables:
   ```bash
   npx drizzle-kit generate:pg
   ```
2. Apply the SQL changes found in `backend/sql/2026-05-29_bill_attachments.sql`
   to your Supabase/PostgreSQL instance.
3. Run the constraint utility:
   ```bash
   npx ts-node src/db/add_constraint.ts
   ```
