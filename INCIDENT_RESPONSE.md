# Incident Response

## Severity
- P0: tenant breach, financial corruption, major outage
- P1: critical workflow failure
- P2: degraded non-critical function

## Response Flow
1. Detect and acknowledge
2. Contain impact
3. Communicate status
4. Mitigate/rollback
5. Validate recovery
6. Publish postmortem with actions

## ERP Critical Incidents
Prioritize journal integrity, stock consistency, and payment safety.
