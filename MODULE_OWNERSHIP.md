# Module Ownership

## Ownership Model
- Primary owner: feature correctness and roadmap alignment.
- Secondary owner: architecture consistency and operability.

## Domains
- Inventory: transfer/move/adjustments, warehouses, bin/batch.
- Accountant: journals, chart of accounts, transaction locks.
- Sales/Purchases: order-to-cash and procure-to-pay flows.
- Shared/Core: reusable controls, shell, routing, theming.
- Backend/Data: APIs, services, tenancy boundaries, migrations.

See `.github/CODEOWNERS` for enforceable review routing.
